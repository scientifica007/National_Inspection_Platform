# Checkpoints

This directory stores accepted milestone/increment checkpoint records.

## Purpose

A checkpoint is evidence that a bounded scope has:
- been implemented or designed as applicable.
- been verified.
- been reviewed.
- had blocking findings corrected.
- reached an explicit gate decision.

## Naming

Recommended:
- `M0_COMPLETE_YYYY-MM-DD.md`
- `S01-I01_PASS_YYYY-MM-DD.md`
- `S01-I02_PASS_YYYY-MM-DD.md`

## Rule

Do not create a PASS checkpoint before the corresponding gate decision exists.

Use:
`docs/CHECKPOINT_RECORD_TEMPLATE.md`
for implementation increments.
